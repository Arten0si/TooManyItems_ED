TooManyItems – Item Vault for Enshrouded            version 1.0.0
=====================================================================
Unofficial, free fan tool. Enshrouded (c) Keen Games GmbH.
Source code: https://github.com/Arten0si/TooManyItems_ED

ENGLISH
-------
Requirements: Windows 10/11 64-bit, Enshrouded from Steam, Microsoft Edge
WebView2 Runtime (already part of Windows 11 and most Windows 10 systems).

1. Unpack this folder anywhere you like (NOT into the game folder),
   e.g. Desktop or Documents\TooManyItems.
2. Start Enshrouded and load your world (single-player or a world you host).
3. Run TooManyItems.exe. The badge in the top-right corner turns green:
   "Connected to game".
4. Pick an item, set the amount, click ADD TO INVENTORY
   (or double-click the item / press Enter).

Nothing is written to the game folder or to your save files on disk.
The app only talks to the running game, like a trainer.
Uninstall: delete this folder (and optionally %LOCALAPPDATA%\TooManyItems_ED).

Game update? If the badge says "Game version not supported", the app has
refused to touch the game (your world is safe). Check for a new version of
TooManyItems on GitHub or Nexus Mods.

Antivirus warning? The app reads and writes the memory of the running game,
which some antivirus programs flag as suspicious (false positive). The full
source code is public on GitHub – you can check it or build the .exe yourself.

Problems? Click "Diagnostics" and send diag.txt + tmi_gui.log
(from this folder) together with your game version.

Tip: back up your saves before using it on your main world:
%LOCALAPPDATA%\Enshrouded\Saves


POLSKI
------
Wymagania: Windows 10/11 64-bit, Enshrouded ze Steama, Microsoft Edge
WebView2 Runtime (jest już w Windows 11 i w większości Windows 10).

1. Rozpakuj ten folder w dowolne miejsce (NIE do folderu gry),
   np. na Pulpit albo do Dokumenty\TooManyItems.
2. Włącz Enshrouded i wczytaj świat (gra solo albo świat, który hostujesz).
3. Uruchom TooManyItems.exe. Znaczek w prawym górnym rogu zrobi się
   zielony: „Połączono z grą”.
4. Wybierz przedmiot, ustaw ilość, kliknij DODAJ DO EKWIPUNKU
   (albo dwuklik na przedmiocie / Enter).

Program nic nie zapisuje w folderze gry ani w plikach zapisu na dysku –
działa tylko na uruchomionej grze, jak trainer.
Odinstalowanie: usuń ten folder (i ewentualnie %LOCALAPPDATA%\TooManyItems_ED).

Aktualizacja gry? Jeśli znaczek pokazuje „Wersja gry nieobsługiwana”, program
odmówił zmian w grze (świat jest bezpieczny). Sprawdź nową wersję
TooManyItems na GitHubie albo Nexus Mods.

Ostrzeżenie antywirusa? Program czyta i zapisuje pamięć działającej gry, co
niektóre antywirusy uznają za podejrzane (fałszywy alarm). Cały kod źródłowy
jest na GitHubie – można go sprawdzić albo samemu zbudować .exe.

Problem? Kliknij „Diagnostyka” i wyślij diag.txt + tmi_gui.log
(z tego folderu) razem z wersją gry.
